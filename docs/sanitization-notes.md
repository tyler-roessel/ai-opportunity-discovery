# Sanitization Notes

This repo is intended for public review. It is not the private operational repo.

## Preserved

- The five-stage workflow.
- Real stage names and state progression.
- Real dry-run/live operating pattern.
- Real design principles: source-aware discovery, evidence preservation, human review, and gated CRM handoff.
- Representative Python code patterns for stage orchestration.
- Representative workflow export shape.
- Authentic failure categories and result summaries.

## Generalized

- Private recruiting/business language became generic GTM/recruiting language.
- Live Airtable/Attio field IDs became readable demo field names.
- Live webhook URLs became placeholders.
- Internal source names became public-safe categories.
- Raw prompts became prompt/rubric summaries.
- Commit history became timeline themes rather than raw private commits.

## Removed

- Real prospects, customers, companies, and people.
- API keys, tokens, webhook URLs, and credential-bearing config.
- Live base IDs, object IDs, field IDs, and record IDs.
- Raw transcript dumps.
- Generated output folders and logs.
- Private strategy docs and internal operating handoffs.

## Reviewer Note

The examples are fake by design. The architecture, state model, review gates, and implementation patterns are the evidence.
